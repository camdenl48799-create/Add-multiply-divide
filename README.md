# Add, Multiply & Divide

A responsive, browser-based math playground for practicing addition, multiplication, and division.

## Play locally
Open `index.html` in a modern browser. No install, build step, account, or API key is required.

## Features
- Addition, multiplication, division, and mixed practice
- Adjustable number ranges and instant feedback
- 60-second speed quiz
- Multiplication memory match
- Balloon Pop and Times-Table Sprint
- 3×3 Speed Escape: solve math locks to navigate the grid and reach the exit
- Printable 1–10 or 1–12 multiplication chart
- Local progress statistics saved in the browser
- Responsive layout for phones, tablets, and desktops

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site. The Pages URL will appear in that section.

## Notes
- The site is built with plain HTML, CSS, and JavaScript.
- It has no external runtime dependencies and does not call an AI API.
- Progress is stored locally in each browser, so it does not sync between devices.
